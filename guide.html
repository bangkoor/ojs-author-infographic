Before you start

You need a Journal Manager or Editor account on an OJS 3 journal, so you can download reports and change the website settings. The tool runs in any current browser on a computer. A phone works for checking, but pasting code into OJS is easier on a computer.

What you will paste on your homepage has five parts:

  • Four countersarticles published, authors, countries, and the share of articles with international authors.
  • World mapa marker for each author country, sized by the number of articles.
  • Where authors come fromyour home country first, then a bar for each other country.
  • Collaborationa ring chart of home-only, mixed and international-only articles.
  • Frequent topicsup to 18 keywords you choose. Left out if the file has no keywords.

1Export and load the CSV

  1. In OJS, go to StatisticsReports and choose Articles Report. OJS downloads a CSV file with one row per submission.
  2. In the tool, drop that file on the green box in step 1, or click the box and choose it.
  3. Check the line under the box. It should say Loaded with the file name and number of rows, followed by the columns the tool found.

Until you load a file, the tool shows an invented example marked Example data. None of those numbers belong to a real journal.

Export with the OJS interface set to English. The tool reads English column names (such as Given Name (Author 1) and Affiliation (Author 1)) and a few Indonesian ones. Column names in other languages are not recognised yet.

2Choose the articles

Journal name

Filled in from the file name when possible. It appears in the source note at the bottom of the infographic, so use the name readers know.

Published from and until

The tool starts with the last three years up to today. Only articles whose First published date falls inside this range are counted. Change the dates if your homepage should cover a different period, for example one volume.

Status counted as published

Normally only Published is ticked. The Articles Report also lists declined and ongoing submissions; leave those unticked unless you have a reason.

Sections to include

Every section is ticked except ones that look like corrections, errata, retractions, editorials, front or back matter and re-uploaded old manuscripts. Untick any other section that should not count as a research article in your journal.

3Check author countries

Each author gets a country from their affiliation or from the Country field in their OJS profile. Abstracts and titles are never used. Choose how the tool decides:

OptionWhat it usesGood for
Affiliation first, then the Country fieldA country named in the affiliation. If there is none, the Country field.Most journals. This is the default.
Affiliation onlyOnly countries named in the affiliation text.Journals where authors often leave the Country field at a default value.
Country field onlyOnly the Country field.Journals whose affiliations rarely name a country.

The tick box below the options counts Indonesian institutions as Indonesia even when the affiliation does not say “Indonesia”. It recognises words such as Universitas, Institut Pertanian, IPB, BRIN, Balai, Taman Nasional and Indonesian city and island names. Untick it for a journal outside Indonesia.

Correcting a country

  1. Start with the Needs checking list. It holds authors with no country and authors whose Country field disagrees with their affiliation.
  2. Read the affiliation and pick the right country from the menu in that row. The infographic updates straight away.
  3. Open International to scan every author outside your home country. A wrong match shows up quickly here, for example an American university named after a place that is also a country.

Corrections last until you load another file or reload the page. They are not saved anywhere.

4Pick the topics

The list shows the 40 most frequent keywords of the selected articles, with the number of articles for each. The most frequent ones are ticked.

  • Tick up to 18 keywords. The two most frequent appear largest on the homepage.
  • Edit a label to tidy it, for example “Ecotourism” instead of “ecotourism”.
  • Give two keywords the same label to merge them. Their counts are added together.

If the file has no Keywords column, or the articles have no keywords, the topics part is left out.

5Style

Label language switches every label, month name and the source note between English and Bahasa Indonesia. Country names follow the same language.

Main colour is used for the counters, the home-country marker and the topics. Accent colour is used for the international markers, bars and the last counter. Pick colours from your journal’s logo or header and keep them dark enough for white text on the counters.

Use OJS column and Phone above the preview to see the section at both widths.

6Paste into OJS

The code comes in two parts. Copy them from the same session, because the CSS carries the positions and widths for the countries in that HTML.

CSS: once per update, in the page header

  1. In the tool, choose CSS and click Copy CSS. The copied text starts with <style>.
  2. In OJS, open SettingsWebsitePlugins, find Custom Header Plugin, enable it, and open its Settings. If it is not listed, install it from the Plugin Gallery tab or ask your OJS administrator.
  3. Paste into the header content field and save. If the field already has code, add the new code below it.

HTML: on the homepage

  1. In the tool, choose HTML and click Copy HTML.
  2. In OJS, open SettingsWebsiteAppearanceSetup and find Additional Content.
  3. Click the editor’s Source code button (<>), place the cursor where the section should go, paste, and save.
  4. Open your journal homepage in a new tab and check the section on a computer and on a phone.

Always paste the HTML in the Source code view. Pasted into the normal editor view, the code appears as text on your homepage, or the editor removes parts of it.

Menu names can differ slightly between OJS versions and themes. If you cannot find a menu, search the OJS documentation for “Custom Header plugin” and “Additional Content”.

How the numbers are counted

NumberHow it is counted
Articles publishedRows with a ticked status, a first published date inside the period, and a ticked section.
AuthorsDifferent people across those articles, matched by name. Someone with three articles counts once. The same person spelled two ways counts twice. Email addresses are not used, because many OJS accounts share placeholder emails.
CountriesCountries with at least one author in the selected articles.
Articles with international authorsArticles with at least one author from outside the home country, as a share of all selected articles. The home country is the one with the most articles.
Map markers and barsThe number of articles with at least one author from that country. An article with authors from two countries counts once for each country.

These numbers can differ from the OJS statistics pages, which count submissions and readership rather than published articles in a chosen period.

Updating later

The infographic is a snapshot. It does not update by itself when new articles are published. After each new issue, or once a year:

  1. Export a new Articles Report and load it in the tool.
  2. Redo your choices: dates, sections, country corrections and topics. The tool keeps nothing from last time.
  3. Replace both the old CSS in the Custom Header and the old HTML in Additional Content. Mixing an old part with a new part puts markers in the wrong place.

When something goes wrong

“The file is missing columns the tool needs”

The file is not the Articles Report, or it was exported with the OJS interface in another language. Download the Articles Report again with OJS set to English.

“No articles match these settings”

Check that Published is ticked in step 2, that the dates cover your published issues, and that at least one research section is ticked.

The homepage shows plain text or a broken layout

The CSS is not reaching the page. Check that the Custom Header plugin is enabled, that the pasted CSS starts with <style>, and that it comes from the same session as the HTML. Then reload the homepage, clearing the browser cache if needed.

Code appears as text on the homepage

The HTML was pasted in the normal editor view. Delete it, open the Source code view and paste again.

Country flags do not appear

Flags load from flagcdn.com. Some networks and browser extensions block outside images. The section still works, with a small grey box in place of each flag.

The numbers do not count up

The counting and map animations are turned off for visitors who ask their device for reduced motion, and older browsers show the final numbers straight away. Both show correct numbers.

A country is clearly wrong

Find the author under International or All authors in step 3 and pick the right country. Then copy both CSS and HTML again.

Your data

The CSV is read inside your browser tab. It is not uploaded to a server and nothing is stored after you close or reload the page. The generated code holds counts, country names and the keywords you pick. It does not hold author names, emails or affiliations.

The tool loads its fonts from Google Fonts and its CSV reader from cdnjs. Your file is not sent to either.
